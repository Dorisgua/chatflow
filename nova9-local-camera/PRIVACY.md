# 隐私设计说明

这个原型只做一件事：在应用位于前台时，把后置摄像头画面传给同一 Wi-Fi 中、持有一次性地址的浏览器。

## 应用申请的权限

- `CAMERA`：读取后置摄像头画面。
- `INTERNET`：Android 使用本地网络套接字也必须声明此权限。
- `ACCESS_NETWORK_STATE`：确认当前连接是 Wi-Fi，并取得 Wi-Fi 的本地地址。

应用不申请麦克风、相册、文件、位置、通讯录、短信、电话、通知、无障碍服务或后台启动权限。

## 应用不会做的事情

- 不创建账号，不登录任何服务。
- 不包含广告、统计、崩溃上报或第三方运行时 SDK。
- 不连接开发者服务器或任何云服务。
- 不读取、写入或保存照片和视频。
- 不读取手机上的其他应用或通知。
- 不在退到后台后继续使用摄像头。

## 网络边界

- 服务器只绑定到当前 Wi-Fi 的私有 IPv4 地址，不绑定移动网络地址。
- 客户端必须来自私有局域网，并提供每次启动随机生成的 128 位令牌。
- 关闭传输或退出应用后，服务器套接字会关闭，内存中的最后一帧会被清除。
- 浏览器连接采用局域网 HTTP，不是 TLS。只应在可信家庭 Wi-Fi 或只有手机与电脑的隔离热点中测试，不应在公共 Wi-Fi 使用。

## 如何人工复核

1. 查看 `AndroidManifest.xml`，确认权限只有上述三项。
2. 搜索 Java 源码中的 `Socket`：只有 `ServerSocket` 和接受浏览器连接的 `Socket`，不存在主动连接外部地址的客户端套接字。
3. 搜索 `File`、`ContentResolver`、`MediaStore`：应用没有文件或相册访问代码。
4. 构建后使用 Android SDK 的 `apkanalyzer manifest permissions` 或 `aapt2 dump permissions` 再次检查 APK。
