# Nova 9：安全的 15 分钟测试流程

## 先不要安装，先核对

电脑上的 APK 文件：`dist/Nova9LocalCamera-v0.1.0.apk`

本次构建的 APK SHA-256：

```text
a79ba811fff01ef12048c531a8d948427ebd83e453de5d0e8c42d4b70e8fecb7
```

测试证书 SHA-256：

```text
82531dfbafe0487e5cdc73a2ce0a4b713cd078128ec4b85740241b5b414f5558
```

打开 `dist/BUILD-REPORT.txt`，确认 APK 权限只有：

- `android.permission.CAMERA`
- `android.permission.INTERNET`
- `android.permission.ACCESS_NETWORK_STATE`

其中只有“摄像头”会在手机上弹出运行时授权。应用不申请麦克风、相册、文件、位置、短信、通讯录、通知、无障碍服务或后台运行权限。

## 安装

1. 通过 USB 文件传输或华为分享，把 APK 复制到手机“下载”目录。不要通过公共网盘或陌生聊天群转发。
2. 在手机文件管理中点击 APK。
3. HarmonyOS 4.2 如果阻止安装，可暂时前往“设置 → 系统和更新 → 纯净模式”，关闭增强防护。
4. 安装界面显示应用名“本地摄像头”。如果出现相机、网络状态之外的敏感权限说明，取消安装。
5. 安装完成后立即重新开启纯净模式的增强防护。

## 运行

1. 手机和电脑连接同一个可信家庭 Wi-Fi，最好使用 5 GHz。
2. 手机电量保持在 40%～80%，取下厚手机壳，测试期间不要充电。
3. 打开“本地摄像头”，只允许摄像头权限。
4. 看到本机预览后，点击“开始局域网传输”。
5. 手机会显示形如 `http://192.168.x.x:8787/?token=...` 的完整地址。
6. 在同一 Wi-Fi 的电脑浏览器中手工输入完整地址。地址中的随机令牌不要发送给别人。
7. 连续观察 15 分钟，记录是否卡顿、断流、明显发热或快速掉电。

如果机身烫手、出现温度警告、相机闪退或电量异常下降，立即点击“停止传输”并退出应用。

## 测试结束

1. 点击“停止传输”。
2. 从手机最近任务中划掉应用。应用进入后台时也会自动关闭服务器并释放摄像头。
3. 前往“设置 → 应用和服务 → 应用管理 → 本地摄像头 → 权限”，撤销摄像头权限。
4. 如果暂时不再测试，直接卸载应用。
5. 这个应用不创建录像文件，因此不需要清理相册或应用数据。

## 已知边界

- 浏览器视频使用家庭局域网 HTTP，不是 TLS；不要在酒店、学校、公司或公共 Wi-Fi 使用。
- APK 使用项目本地测试证书，不是应用商店签名，所以系统会按外部来源应用提示风险。
- 当前只完成了编译和静态检查；首次真机测试仍可能暴露 Nova 9 摄像头格式或省电策略方面的兼容问题。
