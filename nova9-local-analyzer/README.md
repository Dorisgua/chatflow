# Nova 9 本地 YOLO 分析器

这个程序完成一条简单的数据链：

`Nova 9 实时摄像头 → 私有局域网 → 电脑内存 → 本地 YOLO26n → 窗口显示`

## 使用方法

1. Nova 9 和电脑连接同一个可信 Wi-Fi；也可以让其中一台开启热点。
2. 打开手机上的 `Nova 9 Local Camera`，允许摄像头，启动传输。
3. 确认电脑浏览器仍能打开手机显示的完整地址。
4. 双击 `START.cmd`（中文入口 `启动本地识别.cmd` 与它完全相同）。
   会同时出现一个小命令窗口和识别窗口；识别期间请保留命令窗口，它能在启动失败时显示具体原因。
5. 将手机显示的完整地址粘贴进窗口，点击“开始本地识别”。
6. 程序从实时视频流中每秒处理约 1 帧，并画出识别框。
7. 点击“停止并清除画面”后，最近画面会从程序内存中清除。

## 如何验证断网仍能运行

“断网”是断开互联网，不是切断手机和电脑之间的 Wi-Fi：

1. 先确保程序已经启动过一次，模型可以正常加载。
2. 拔掉路由器的入户网线，或关闭路由器的互联网连接。
3. 保持手机和电脑仍连接同一个 Wi-Fi/热点。
4. 再启动手机传输和电脑识别；若仍有识别框，就证明运行不依赖云端。

## 文件说明

- `src/Nova9LocalAnalyzer.java`：全部电脑端业务代码，可直接阅读。
- `models/yolo26n.onnx`：官方下载的 Ultralytics YOLO26n ONNX 模型。
- `lib/onnxruntime-1.26.0.jar`：官方下载的 Microsoft ONNX Runtime Java 包。
- `START.cmd`：双击启动程序；中文入口 `启动本地识别.cmd` 只是调用它。
- `BUILD.cmd`：从源代码重新生成 class 文件。
- `SELF_TEST.cmd`：重新编译，并验证私有网络限制、ONNX Runtime、模型加载和一次本地推理。
- `PRIVACY.md`：隐私边界和验证方法。
- `SHA256.txt`：关键文件的校验值。

## 能力边界

模型只认识 COCO 的 80 类常见物体。它不做人脸识别，不读取手机相册、银行应用、密码、麦克风或通讯录。识别效果受光线、距离、遮挡和镜头清晰度影响。
