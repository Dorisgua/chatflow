# Nova 9 本地活动日历

状态：第一版电脑周日历已经实现；手机查看仍处于后续设计阶段。

这个独立模块把已经生成的最小化活动总结呈现为电脑周日历和手机单日时间线。它不负责摄像头采集或模型推理，也不会读取图片、视频和模型原始回答。

## 数据来源

第一版只读取：

```text
D:\Documents\chatflow\nova9-activity-records\年-月\日期\daily-summary.md
```

该文件目前只包含日期、时间段、活动类别和可信度。日历模块默认只读，不修改场景理解程序或历史记录。

## 已实现功能

1. 电脑端一周七列活动日历，按真实时间比例绘制活动格子。
2. 支持上一周、下一周、今天、最近记录和手动刷新。
3. 短活动保留为细色条，不为显示效果虚构很长的持续时间。
4. 数据缺失使用灰色斜纹；空白仅表示没有已保存的记录。
5. 点击格子查看时间、预计时长、类别和可信度。
6. 只读取 `daily-summary.md`，不打开加密详情、图片、视频或模型原始回答。

## 如何运行

在文件资源管理器中双击：

```text
D:\Documents\chatflow\nova9-local-calendar\启动活动日历.cmd
```

程序默认打开本周。如果本周没有记录，可以点击“最近记录”。窗口是只读视图，不会修改或重新保存任何活动文件。

需要验证解析、时长估算和界面渲染时，可以双击 `日历自检.cmd`。

## 后续功能

用户主动开启手机查看后，在同一私有局域网提供适配手机的月历和单日时间线；默认不上传云端、不接入系统日历，也不传输图片和视频。

## 模块边界

- `nova9-local-camera`：负责手机摄像头采集和局域网传输。
- `nova9-local-scene`：负责本地模型推理、活动记录和加密保存。
- `nova9-local-calendar`：只负责读取最小摘要并呈现、共享日历。
- `nova9-activity-records`：用户数据目录，不复制进本项目。

详细界面和数据规则见 `DESIGN.md`，隐私边界见 `PRIVACY.md`。

## 主要文件

- `src/SavedSummaryReader.java`：只读取每日最小化活动总结。
- `src/ActivityCalendarModel.java`：按周组织历史记录并查找最近日期。
- `src/ActivityPeriod.java`：保存一个只含文字的活动时间段。
- `src/ActivityWeekGrid.java`：绘制按时间比例排列的七列周视图。
- `src/ActivityCalendarPanel.java`：日期导航、详情和只读状态界面。
- `src/CalendarSelfTest.java`：使用临时虚构摘要验证解析和渲染，不读取真实详细记录。
