# 隐私边界

当前第一版是纯本地只读程序：它会读取已保存的 `daily-summary.md` 来绘制周日历，但不会写入或修改用户记录，也没有网络服务。

计划实现必须遵守以下边界：

- 不读取、复制或提供图片和视频。
- 不读取加密详细记录和模型原始回答。
- 第一版只读最小化的 `daily-summary.md`；源码中唯一的正式记录读取入口限定为这个文件名。
- 不把 `nova9-activity-records` 复制到代码目录或备份目录。
- 不连接云服务、系统日历、统计 SDK、遥测服务或在线字体/CDN。
- 当前版本没有手机接口、监听端口或联网代码。
- 后续手机查看必须默认关闭，只能由用户主动开启，并可随时停止。
- 后续手机接口不得返回摄像头地址、访问令牌、模型 API 密钥或记录密码。
- 后续服务只能允许私有局域网连接，使用随机临时凭据并明确禁止缓存。
- 第一版不在手机上永久保存记录；离线保存必须作为单独功能重新设计和审查。

活动类别与时间本身也属于敏感生活信息。即使不包含图片，仍应避免使用公共或不可信 Wi-Fi 开启手机查看。
