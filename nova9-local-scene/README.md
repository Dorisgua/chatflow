# Nova 9 本地场景理解

这个独立工具把 Nova 9 摄像头画面交给电脑上的 MiniCPM-V 4.6，生成中文场景描述；也可每2分钟生成一条详细的本地文字活动记录。

数据链：

`Nova 9 → 私有局域网 → Java 内存中的最近3帧 → 127.0.0.1 上的 llama.cpp → 本地 MiniCPM-V → 窗口文字`

## 正常使用

1. Nova 9 与电脑连接同一个可信 Wi-Fi或热点。
2. 手机打开之前安装的 `Nova 9 Local Camera`，启动传输。
3. 双击本目录的 `START.cmd`（中文入口 `启动本地场景理解.cmd` 与它相同），保留随之出现的小命令窗口。
4. 把手机显示的完整地址粘贴进窗口，点击“启动本地场景理解”。
5. 模型第一次加载可能需要几十秒。默认开启“Demo 快速模式”：每次只分析最新一帧，并用一句话描述场景；程序每10秒尝试更新一次，但若 CPU 上一轮尚未完成，会等待而不重叠运行。
6. 可点击“立即描述一次”；上一轮尚未完成时不会重复提交。
7. 如需原来的谨慎分析，取消勾选“Demo 快速模式”，程序会使用最近3帧并输出观察、推测和不确定性。
8. 结束时点击“停止并清除”，然后关闭手机摄像头应用。

如果连续10秒没有收到新帧，程序会清除旧预览和内存帧、暂停推理，并在记录模式下添加“数据缺失”事件；连续两次检查都收到新帧后自动恢复。中断期间不会重复分析最后一张旧画面。

## 活动记录

1. 等模型就绪后点击“开始活动记录”。普通自动描述会暂停，程序每2分钟只分析最新一帧。
2. “当前显示”展示整理后的详细内容；“模型原始回答”展示未经删减的原始 `content`；“今日时间线”展示时间、活动类别、可信度和本次推理耗时。
3. 点击“暂停记录”可停止新增记录；当前文字仍只在运行内存中。
4. 点击“加密保存今天”，输入两次至少8字符的密码。密码只在本次保存期间存在于内存，忘记后无法恢复详细文件。
5. 点击“打开加密记录”可选择保存的 `activity-details.json.enc` 并在本机解密查看。

保存目录与程序目录分离：

`D:\Documents\chatflow\nova9-activity-records\年-月\日期\`

- `activity-details.json.enc`：AES-256-GCM 加密的完整详细文字，包含模型原始回答、整理结果和技术参数；
- `daily-summary.md`：未加密的简要时间线，只包含时间、活动类别和可信度；
- `record-info.json`：未加密的非敏感格式、模型和加密方式说明。

任何记录文件都不包含图片、视频、手机地址、令牌或本地模型 API 密钥。保存不是自动执行的，必须由用户点击“加密保存今天”。

## 输出原则

程序要求模型区分：

- `观察`：画面中可以直接看到的物体、位置和动作；
- `推测`：最可能的场景活动；
- `不确定性`：不能仅凭画面确认的内容。

例如它应该说“桌旁两人面前有杯子，可能在喝饮品交流”，而不是断言杯中一定是茶或两人一定在交谈。

## 离线验证

模型和运行器已经放在本目录，正常启动命令只使用本地文件路径，不使用自动下载参数。

1. 先在联网状态运行并通过一次测试。
2. 关闭程序。
3. 关闭手机移动数据或断开路由器外网，但保留手机与电脑之间的 Wi-Fi/热点。
4. 再次从 `START.cmd` 完整启动并生成描述。
5. 若仍成功，说明推理运行不依赖互联网。

## 文件说明

- `src/Nova9LocalScene.java`：网络限制、内存采样、模型调用和窗口。
- `src/ActivityRecord.java`：固定活动类别、模型原始回答和结构化详细记录。
- `src/EncryptedRecordStore.java`：AES-GCM 加密保存、明文最小化总结和本地解密。
- `src/RecordStorageSelfTest.java`：不接触真实画面的记录加密自检。
- `models/`：OpenBMB MiniCPM-V 4.6 本地 GGUF 模型。
- `runtime/`：ggml-org 官方 llama.cpp Windows CPU 运行器。
- `BUILD.cmd`：从源码重新编译。
- `SELF_TEST.cmd`：校验模型，并用合成图片完成一次真实本地推理。
- `RECORD_SELF_TEST.cmd`：测试详细记录解析、正确密码解密、错误密码拒绝和明文总结最小化。
- `PRIVACY.md`：隐私边界。
- `SHA256.txt`：第三方大文件校验值。

## 现实限制

- 视觉模型可能产生错误推测，输出不能作为事实证据。
- 没有声音，因此无法确认人是否正在说话。
- 模型只看到摄像头覆盖范围，而不是用户的完整环境。
- CPU 生成速度需要以本机实际结果为准。
